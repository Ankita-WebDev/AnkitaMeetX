# AnkitaMeetX  
A simple and modern video meeting application built using **React**, **Node.js**, **WebRTC**, and **Socket.io**.  
Users can create or join meetings, authenticate themselves, and view their meeting history.

---

## 🚀 Features

### 🔐 Authentication System
- User Registration  
- Secure Login  
- Token-based authentication (JWT)  

### 🎥 Video Conferencing
- Real-time video and audio meetings  
- Unique meeting code join  
- Auto navigation to meeting page  
- Add meeting activity to user history  

### 🏠 Dashboard
- Home page with "Create Meeting" and "Join Meeting"  
- Meeting history page

## 📦 Installation Guide

### 1️⃣ Clone the repository
```bash
git clone https://github.com/Ankita-WebDev/AnkitaMeetX.git
```

### 2️⃣ Install frontend dependencies
```bash
cd frontend
npm install
```

### 3️⃣ Install backend dependencies
```bash
cd ../backend
npm install
```

---

## ▶️ Run the App

### Start Backend
```bash
cd backend
npm start
```

### Start Frontend
```bash
cd frontend
npm start
```
